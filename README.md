# 学校祭 非同期カメラ映像ストリーマー

OpenCV のカメラ映像を JPEG/Base64 にして ZeroMQ PUB/SUB で配信します。送受信する両方のマシンに Python 3.14 以降と `uv` が必要です。

## 配信側

カメラを接続し、リポジトリで依存関係を準備してから起動します。

```sh
uv sync
uv run school-festival-async-messenger host
```

既定ではカメラ番号 `0`、JPEG 品質 `85`、`tcp://*:5555` で配信します。必要に応じて変更できます。

```sh
uv run school-festival-async-messenger host --camera 1 --quality 70 --bind tcp://*:5555
```

配信側でも画質を確認する場合は `--preview` を指定します。

```sh
uv run school-festival-async-messenger host --preview
```

送信した JPEG を復号して OpenCV のネイティブウィンドウに表示するため、JPEG 品質の影響を確認できます（受信側への到達を保証する表示ではありません）。GUI デスクトップ環境が必要です。ウィンドウを選択して `q` または Esc を押すと配信も終了します。Ctrl-C でも終了できます。既定ではウィンドウを開かず、GUI 操作は行いません。

bind 成功後、実際の配信アドレスと `client --connect ...` の起動例を INFO ログに表示します。`--bind tcp://192.168.1.20:6001` のような明示アドレスでは、そのアドレス・ポートを案内します。`*` / `0.0.0.0` は接続先に使えないため、ホスト名から取得できるローカル IPv4 を接続先候補として表示します。外部ネットワークへの接続による探索は行いません。候補が得られない場合は、同じマシン専用の `127.0.0.1` を案内します。IPC の場合は TCP アドレスに置き換えません。

## 受信側

受信側にもリポジトリと依存関係が必要です。`HOST_IP` を配信側マシンの LAN 内 IP アドレスに置き換えます。

```sh
uv sync
uv run school-festival-async-messenger client --connect tcp://HOST_IP:5555
```

受信側には GUI デスクトップ環境が必要です（OpenCV のネイティブウィンドウを表示します）。映像ウィンドウで `q` または Esc、あるいはターミナルで Ctrl-C を押すと終了します。

## 注意事項

- 配信側のファイアウォールで TCP ポート 5555 への接続を許可してください。別ポートを使う場合は、配信側の `--bind` と受信側の `--connect` を合わせます。
- 起動ログの IPv4 候補はホスト名の解決結果に限られ、すべての LAN アドレスを取得できるとは限りません。VPN・複数 NIC・名前解決設定などで候補が異なります。LAN からの到達性は保証されないため、必要なら OS のネットワーク設定で IP を確認し、経路・ファイアウォールも確認してください。`127.0.0.1` には別のマシンから接続できません。
- この通信は暗号化・認証されません。信頼できる LAN 内だけで使用し、インターネットに公開しないでください。
- JPEG は非可逆圧縮です。PUB/SUB は最新フレームを優先して古いフレームを捨てるため、接続直後や回線混雑時にはフレームが欠落します。Base64 により JPEG データ量は約 4/3 になります。
- カメラ利用権限と、OpenCV が利用できるカメラデバイスが必要です。
